# Premium Service Ordering System Backend

This is the Node.js backend for the Premium Service Ordering System. It provides REST APIs for order management, payment status, and admin operations.

## Structure
- `src/` - Source code
  - `routes/` - API route definitions
  - `controllers/` - Business logic
  - `models/` - Database models
  - `db/` - MySQL connection
  - `utils/` - Helper functions

## Setup
1. Copy `.env.example` to `.env` and fill in your MySQL credentials.
2. Run `npm install` to install dependencies.
3. Run `npm start` to start the server.

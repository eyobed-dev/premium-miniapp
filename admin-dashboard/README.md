# Premium Service Ordering System Admin Dashboard

This is the React-based admin dashboard for managing premium service orders. It allows admins to view, filter, and complete orders.

## Structure
- `src/` - Source code
  - `pages/` - Page components (Orders, Login, etc.)
  - `components/` - Reusable UI components
  - `services/` - API calls
  - `utils/` - Helper functions

## Setup
1. Run `npm install` to install dependencies.
2. Run `npm start` to start the dashboard.
